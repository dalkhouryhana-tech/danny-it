two Flutter apps, one Supabase backend

An admin dashboard and a driver app that share a database but must never share data past their own role. Built as two separate codebases on purpose, so a driver-facing bug can't accidentally expose manager features.

  • Manager app: orders, drivers, delivery areas, expenses and reports, with order creation and captain assignment.
  • Captain app: a driver signs in and sees only their own assigned orders, live, via Supabase Realtime.
  • Per-captain commission percentages are set on the driver record and calculated automatically when an order is created — never entered by hand, and never rewritten by a later rate change.
  • Postgres Row-Level Security enforces the same access boundary independently of the app code, as a second line of defense.
